# المكتبة المفتوحة (OpenLibrary)

هذا المشروع عبارة عن برنامج لقراءة وفتح الكتب بصيغة **EPUB**.

## الخطط المستقبلية
- إضافة دعم لفتح وقراءة ملفات **BOK** في التحديثات القادمة إن شاء الله.

## التقنيات المستخدمة
تم بناء هذا المشروع باستخدام مجموعة من التقنيات لضمان الأداء السريع:
- **لغة C++**: اللغة الأساسية لتطوير المشروع.
- **Slint**: لبناء واجهة المستخدم (UI).
- **libzip**: للتعامل مع ملفات EPUB وفك ضغطها.
- **pugixml**: لقراءة وتحليل بيانات XML داخل ملفات الكتب.
- **nativefiledialog-extended**: للتعامل مع نوافذ اختيار الملفات في النظام.

## بناء المشروع
للقيام ببناء المشروع، تحتاج أولاً إلى تثبيت الحزم المطلوبة (التعليمات التالية مخصصة لتوزيعات Arch Linux):

```bash
# الحزم المطلوبة لبناء المشروع
# =============================================

# واجهة المستخدم Slint
yay -S slint-cpp-bin

# مكتبة فك ضغط ZIP (لقراءة ملفات EPUB)
sudo pacman -S libzip

# مكتبة GTK3 (لمدير الملفات nativefiledialog)
sudo pacman -S gtk3

# أدوات البناء الأساسية
sudo pacman -S cmake base-devel pkg-config
```

بعد تثبيت الحزم، قم بتنفيذ الأمر التالي في مسار المشروع لعمل البناء (Build):
```bash
cmake . && make -j$(nproc)
```
